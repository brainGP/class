Static vs Dynamic Data

Бид өмнө нь өгөгдлийг өөрсдөө бичиж ашиглаж байсан. Үүнийг Static Data гэдэг.

const users = [
{ name: "Bat" },
{ name: "Anu" }
];

Харин бодит системд өгөгдөл серверээс ирдэг. Үүнийг Dynamic Data гэдэг.

fetch("https://jsonplaceholder.typicode.com/users")
  • Static → өөрсдөө бичсэн
  • Dynamic → backend-ээс ирдэг

fetch() гэж юу вэ?

fetch() нь сервер рүү хүсэлт (request) явуулж өгөгдөл авах функц юм.

fetch("https://jsonplaceholder.typicode.com/users") .then(res => res.json()) .then(data => console.log(data));

Яаж ажилладаг вэ?

  1. fetch → сервер рүү хүсэлт явуулна
  2. response ирнэ
  3. res.json() → JSON болгож хөрвүүлнэ
  4. data → бид ашиглана

Энэ нь бодит апп-д хамгийн их ашиглагддаг зүйл

Яагаад fetch ашиглах ёстой вэ?

  • Бодит өгөгдөл авахын тулд
  • Backend-тэй холбогдохын тулд
  • Dynamic website хийхийн тулд
Frontend → fetch() → Backend → JSON → UI

JSON бүтэц

{
  "name": "Dorj",
  "age": 18,
  "city": "Ulaanbaatar"
}
  • Key → "name" (заавал " " дотор бичигдэнэ)
  • Value → утга (string, number, boolean, array)
  • Object → { }

Object vs Array ялгаа

JSON дотор хамгийн их ашиглагддаг 2 бүтэц бол Object болон Array юм.

1. Object

{
  "name": "Bat",
  "age": 18
}
  • Нэг зүйл (single data)-г илэрхийлнэ
  • Key → value бүтэцтэй
  • Тодорхой мэдээлэл хадгална (нэг хүн, нэг бүтээгдэхүүн)

2. Array

[
  { "name": "Bat" },
  { "name": "Anu" }
]
  • Олон зүйл (list of data) хадгална
  • Index ашиглаж хандана (0, 1, 2...)
  • Ихэнх API array буцаадаг ❗

Гол ялгаа

Object → нэг зүйл (user)
Array → олон зүйл (users)

map() + fetch()

Өмнө нь бид static array дээр map ашигласан. Одоо API-аас ирсэн data дээр map ашиглана.

fetch("https://jsonplaceholder.typicode.com/users") .then(res => res.json()) .then(users => { const list = document.getElementById("list"); users.map(user => { const li = document.createElement("li"); li.innerText = user.name; list.appendChild(li); }); });

👉 users array-г бид бичээгүй ч map ажиллаж байна!

async / await гэж юу вэ?

fetch() нь серверээс data авах үед шууд хариу өгдөггүй. Түр хугацаа шаардагддаг тул бид хүлээх хэрэгтэй болдог.

жишээ:

Та кофе захиаллаа гэж бодъё

  • Захиалга өгнө
  • Хүлээнэ
  • Кофе ирнэ

Хэрвээ хүлээхгүй бол → кофе авч чадахгүй

await байхгүй (алдаа)

function getData() {
const res = fetch("https://jsonplaceholder.typicode.com/users");
console.log(res);
}
getData();

  • fetch нь шууд data биш, Promise (ирээдүйд data өгнө гэсэн амлалт) буцаадаг
  • data харагдахгүй ❗

async / await гэж юу вэ?

async function getData() {
  console.log("1. function эхэллээ");

  console.log("2. server рүү явж байна...");
  const res = await fetch("https://jsonplaceholder.typicode.com/users");

  console.log("3. server-ээс хариу ирлээ");
  const data = await res.json();

  console.log("4. data бэлэн боллоо");
  console.log(data);
}

console.log("A. function дуудахын өмнө");
getData();
console.log("B. function дуудасны дараа");
  • async -> "энэ function жаахан удаан ажиллана" гэж JS-д хэлж байна
  • await -> Promise - "энэ хэсэг дээр түр хүлээ" гэсэн үг
  • fetch -> execution order - "интернетээс data авч ирнэ"

Яг юу болж байна вэ?

  1. JS function-ийг эхлүүлнэ
  2. server рүү data гуйна
  3. хариу иртэл түр хүлээнэ
  4. data ирмэгц үргэлжлүүлнэ
await = "түр хүлээ (data иртэл)"

await байхгүй бол JS шууд цаашаа явчихна, data бэлэн биш байдаг ❗

Бодит амьдралтай жишээ

  • Чи кофе захиална
  • barista хийж эхэлнэ
  • чи түр хүлээнэ
  • кофе бэлэн болоод ирнэ

async = кофе хийх процесс
await = кофе бэлэн болохыг хүлээх

API -> UI (User List App)

https://jsonplaceholder.typicode.com/albums

Бид API-с хэрэглэгчдийн мэдээлэл авч, UI дээр харуулна.

    async function loadUsers() {
    const list = document.getElementById("userList");
    list.innerText = "Loading...";

    const res = await fetch("https://jsonplaceholder.typicode.com/users");
    const users = await res.json();

    list.innerText = "";

    users.map(user => {
    const li = document.createElement("li");

    li.className = "p-4 bg-white rounded shadow";

    li.innerHTML = `
    ${user.name}
    ${user.email}
    ${user.address.city}

    `;

    list.appendChild(li);
    });
    }

    loadUsers();

    async function loadUsers() → API-с хэрэглэгчдийн мэдээлэл авах function үүсгэж байна. async нь await ашиглах боломж олгодог.

    document.getElementById("userList") → HTML дээрх userList элементийг авч, data харуулах хэсгийг зааж байна.

    list.innerText = "Loading..." → Data ирэх хүртэл “ачаалж байна” гэж харуулж байна.

    await fetch(...) → API руу хүсэлт явуулж, серверийн хариу иртэл хүлээж байна.

    await res.json() → серверээс ирсэн response-г JSON формат руу хөрвүүлж, users хувьсагчид хадгалж байна.

    list.innerText = "" → Loading текстийг устгаж, шинэ data харуулахад бэлдэж байна.

    users.map(user => {...}) → users array доторх бүх хэрэглэгч дээр нэг нэгээр нь ажиллаж байна.

    document.createElement("li") → шинэ HTML элемент үүсгэж байна (нэг хэрэглэгч = нэг card).

    li.className → Tailwind ашиглан дизайныг тохируулж байна.

    li.innerHTML → хэрэглэгчийн нэр, email, city-г HTML дотор оруулж байна.
    user.address.city нь nested object-с data авч байна.

    list.appendChild(li) → үүсгэсэн элементийг HTML дээр нэмэж, харагдуулж байна.

    loadUsers() → function-г ажиллуулж байна. Энэ мөр байхгүй бол юу ч болохгүй.
