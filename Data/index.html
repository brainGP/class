Fetch & API

Async/await, fetch, бодит API дуудлага.

Static vs Dynamic өгөгдөл

Өмнө нь өгөгдлийг өөрсдөө бичиж ашиглаж байсан — үүнийг Static гэдэг.

const users = [ { name: "Bat" }, { name: "Anu" } ];

Бодит системд өгөгдөл серверээс ирдэг — үүнийг Dynamic гэдэг.

fetch("https://jsonplaceholder.typicode.com/users")
Static → өөрсдөө бичсэн өгөгдөл
Dynamic → сервер (backend)-ээс ирдэг өгөгдөл

fetch() гэж юу вэ?

fetch() нь сервер рүү хүсэлт (request) явуулж өгөгдөл авах функц юм.

fetch("https://jsonplaceholder.typicode.com/users") .then(res => res.json()) .then(data => console.log(data));
  1. fetch → сервер рүү хүсэлт явуулна
  2. response ирнэ
  3. res.json() → JSON болгож хөрвүүлнэ
  4. data → бид ашиглана

Яагаад fetch ашиглах ёстой вэ?

  • → Бодит өгөгдөл авахын тулд
  • → Backend-тэй холбогдохын тулд
  • → Dynamic website хийхийн тулд
Frontend → fetch() → Backend → JSON → UI

async / await гэж юу вэ?

fetch() нь серверээс data авах үед шууд хариу өгдөггүй — бид хүлээх хэрэгтэй.

Бодит жишээ — кофе захиалах:

1. Захиалга өгнө → 2. Хүлээнэ → 3. Кофе ирнэ

Хэрвээ хүлээхгүй бол кофе авч чадахгүй — яг л await байхгүй бол data авч чадахгүй.

await байхгүй бол (алдаа):

function getData() { const res = fetch("https://jsonplaceholder.typicode.com/users"); console.log(res); // Promise буцаана, data биш! } getData();

async / await ашигласан зөв хэлбэр:

async function getData() { console.log("1. function эхэллээ"); console.log("2. server рүү явж байна..."); const res = await fetch("https://jsonplaceholder.typicode.com/users"); console.log("3. server-ээс хариу ирлээ"); const data = await res.json(); console.log("4. data бэлэн боллоо"); console.log(data); } getData();
  • async → "энэ function жаахан удаан ажиллана" гэж JS-д хэлж байна
  • await → "энэ хэсэг дээр түр хүлээ" гэсэн үг
  • await байхгүй бол JS шууд цаашаа явчихна, data бэлэн биш байдаг

map() + fetch()

API-аас ирсэн data дээр map ашиглана.

fetch("https://jsonplaceholder.typicode.com/users") .then(res => res.json()) .then(users => { const list = document.getElementById("list"); users.map(user => { const li = document.createElement("li"); li.innerText = user.name; list.appendChild(li); }); });

API → UI (бодит жишээ)

API-с хэрэглэгчдийн мэдээлэл авч, UI дээр харуулна. API хаяг →

Үр дүн

    async function loadUsers() { const list = document.getElementById("userList"); list.innerHTML = "<li class='text-gray-400 text-sm'>Ачаалж байна...</li>"; const res = await fetch("https://jsonplaceholder.typicode.com/users"); const users = await res.json(); list.innerHTML = ""; users.map(user => { const li = document.createElement("li"); li.className = "p-3 bg-white border border-gray-200 rounded-lg"; li.innerHTML = ` <div class="font-medium text-sm">${user.name}</div> <div class="text-xs text-gray-500">${user.email}</div> <div class="text-xs text-gray-400">${user.address.city}</div> `; list.appendChild(li); }); } loadUsers();

    async function loadUsers() → API-с өгөгдөл авах function.

    await fetch(...) → API руу хүсэлт явуулж, хариу иртэл хүлээнэ.

    await res.json() → response-г JSON болгож users-т хадгална.

    users.map(user => {...}) → бүх хэрэглэгч дээр нэг нэгээр ажиллана.

    list.appendChild(li) → үүсгэсэн элементийг HTML-д нэмж харагдуулна.
