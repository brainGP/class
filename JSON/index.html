JSON гэж юу вэ?

JSON нь өгөгдлийг хадгалах, дамжуулах зориулалттай стандарт формат юм.

Backend → JSON → Frontend

JSON нь backend-ээс ирсэн мэдээллийг frontend дээр ашиглахад хэрэглэгддэг.

Array гэж юу вэ?

const names = ["Bat", "Anu", "Bold"];

Array = олон өгөгдөл хадгалах

JSON бүтэц

{
  "name": "Dorj",
  "age": 18,
  "city": "Ulaanbaatar"
}
  • Key → "name" (заавал " " дотор бичигдэнэ)
  • Value → утга (string, number, boolean, array)
  • Object → { }

JSON өгөгдлийн төрөл

{
  "name": "Dorj",
  "age": 18,
  "isStudent": true,
  "skills": ["JS", "HTML"],
  "address": { "city": "UB" }
}
  • String → "text"
  • Number → 123
  • Boolean → true / false
  • Array → [ ]
  • Object → { }

Array JSON

[
  { "name": "Bat" },
  { "name": "Anu" },
  { "name": "Bold" }
]

Array JSON нь олон объект хадгалах үед ашиглагддаг.

JSON бичих дүрэм

  • Key заавал "double quote" дотор байна
  • Value төрөл өөр байж болно
  • Сүүлд comma (,) тавихгүй
  • Function бичиж болохгүй
❌ Буруу: { name: "Bat" }
✅ Зөв: { "name": "Bat" }

Mapping гэж юу вэ?

Mapping гэдэг нь array доторх бүх элемент дээр нэг үйлдэл хийх процесс юм.

Array → map() → нэг нэгээр нь ажиллана

Жишээ: list доторх бүх нэрийг нэг нэгээр нь гаргах

JSON → UI (map ашиглах)

Одоо бид JSON өгөгдлийг вэб дээр хэрхэн харуулдагийг сурна. Үүний тулд map() ашиглана.

const users = [
  { name: "Bat" },
  { name: "Anu" }
];

Энэ бол array of objects. Өөрөөр хэлбэл олон хэрэглэгчийн мэдээлэл байна.

map() гэж юу вэ?

map() гэдэг нь array доторх бүх элемент дээр нэг нэгээр нь ажил хийх функц юм.

users.map(user => { console.log(user.name); });

Энэ кодыг задалж ойлгоё

  • users → өгөгдлийн жагсаалт (array)
  • .map() → энэ array доторх бүх item дээр давталт хийх функц
  • user → нэг элемент (нэг хүн)
  • user => → “энэ нэг элемент дээр хийх үйлдэл” гэж хэлж байна

Товчоор:
user = нэг хүн
=> = “энэ хүн дээр юу хийх вэ?” гэж тодорхойлж байна

DOM дээр харуулах

Одоо бид зөвхөн console биш, HTML дээр харуулна.

const list = document.getElementById("list");

Энэ нь HTML доторх list гэсэн хэсгийг олж авч байна.

users.map(user => { const li = document.createElement("li"); li.innerText = user.name; list.appendChild(li); });

Алхам алхмаар юу болж байна?

  1. users array доторх нэг хүн (user) авна
  2. li гэсэн шинэ HTML элемент үүсгэнэ
  3. li дотор тухайн хүний нэрийг бичнэ
  4. HTML list дотор нэмнэ (харагдуулна)
