JSON

Өгөгдлийн формат, array, mapping.

JSON гэж юу вэ?

JSON нь өгөгдлийг хадгалах, дамжуулах зориулалттай стандарт формат юм.

Backend → JSON → Frontend

JSON нь backend-ээс ирсэн мэдээллийг frontend дээр ашиглахад хэрэглэгддэг.

Array гэж юу вэ?

const names = ["Bat", "Anu", "Bold"];

Array = олон өгөгдөл хадгалах жагсаалт.

Array Methods

Array дотор өгөгдөлтэй ажиллах чухал функцүүд.

const numbers = [1, 2, 3, 4, 5];

1. map() — бүх элемент дээр нэг үйлдэл хийнэ

numbers.map(n => n * 2); // → [2, 4, 6, 8, 10]

2. filter() — нөхцөл хангасан элементүүдийг буцаана

numbers.filter(n => n > 2); // → [3, 4, 5]

3. find() — эхний тохирсон утгыг буцаана

numbers.find(n => n === 3); // → 3

4. reduce() — бүх утгыг нэгтгэнэ

numbers.reduce((sum, n) => sum + n, 0); // → 15

JSON бүтэц

{ "name": "Dorj", "age": 18, "city": "Ulaanbaatar" }
  • Key → "name" (заавал " " дотор бичигдэнэ)
  • Value → утга (string, number, boolean, array)
  • Object → { }

JSON өгөгдлийн төрөл

{ "name": "Dorj", // String "age": 18, // Number "isStudent": true, // Boolean "skills": ["JS", "HTML"], // Array "address": { "city": "UB" } // Object }

Object vs Array ялгаа

Object — нэг зүйл

{ "name": "Bat", "age": 18 }

Array — олон зүйл

[ { "name": "Bat" }, { "name": "Anu" } ]
Object → нэг хүн (user)
Array → олон хүн (users) — ихэнх API array буцаадаг!

JSON бичих дүрэм

  • ✗ Key заавал "double quote" дотор байна
  • ✗ Сүүлийн элементэд comma (,) тавихгүй
  • ✗ Function бичиж болохгүй
❌ Буруу: { name: "Bat" } ✅ Зөв: { "name": "Bat" }

JSON → UI (map ашиглах)

Array дотор өгөгдлийг HTML дээр нэг нэгээр нь харуулах.

const users = [ { name: "Bat" }, { name: "Anu" } ]; const list = document.getElementById("list"); users.map(user => { const li = document.createElement("li"); li.innerText = user.name; list.appendChild(li); });
  1. users array дотор нэг хүн (user) авна
  2. li гэсэн шинэ HTML элемент үүсгэнэ
  3. li дотор тухайн хүний нэрийг бичнэ
  4. HTML list дотор нэмнэ (харагдуулна)

Template String — ${ }

Текст болон өгөгдлийг хялбараар холбох арга.

Хуучин арга (+)

"Нэр: " + name + " нас: " + age

Шинэ арга (template string)

`Нэр: ${name} нас: ${age}`
li.innerHTML = `<div>${user.name}</div>`;

Дадлага

Доорх JSON-г UI дээр харуул:

const products = [ { name: "iPhone", price: 1000 }, { name: "Laptop", price: 2000 } ]; // map ашиглан бүтээгдэхүүн бүрийг // div болгон харуул
