→ Бид тэр серверийг өөрсдөө бичиж сурна.

2

npm init — төслийг танилцуулах

npm нь Node.js-н "дэлгүүр" — бусад хүмүүсийн бичсэн кодыг татаж авах хэрэгсэл.
npm init нь чиний төслийн "паспорт" болох package.json файлыг үүсгэнэ.

VS Code терминалд бич (Ctrl+`):

npm init -y

Дараа нь package.json файл үүснэ — яг ингэж харагдана:

{ "name": "my-songs-api", "version": "1.0.0", "main": "index.js", "scripts": { "start": "node index.js" } }

"name"

Чиний төслийн нэр

"main": "index.js"

Сервер эхэлдэг файл

"scripts"

npm start гэхэд юу ажиллуулах вэ

-y гэж юу вэ?

Бүх асуултад автоматаар "тийм" хэлнэ

3

Package татах — express, mongoose, dotenv

3 package татна. Нэг л мөр бичихэд болно:

npm install express mongoose dotenv
express Веб сервер барих framework

"/songs" хуудас нээхэд яах вэ гэдгийг зааж өгдөг. Гэргийн хаалга шиг — хэн орж ирвэл юу хийх.

mongoose MongoDB-тай ярих хэрэгсэл

MongoDB (өгөгдлийн сан) руу хялбараар өгөгдөл хийж, гаргаж авах боломж. Mongoose байхгүй бол MongoDB-тай ярих маш хэцүү.

dotenv Нууц мэдээлэл унших хэрэгсэл

MongoDB-н нууц үгийг кодод шууд бичиж болохгүй. .env файлд хийж, dotenv ашиглан уншдаг.

Суулгасны дараа node_modules хавтас үүснэ — тэнд бүх tataj авсан код байна. Git-д оруулахгүй.
4

MongoDB Atlas — үнэгүй өгөгдлийн сан

MongoDB Atlas нь үнэгүй cloud database. Дуунуудаа тэнд хадгална.

  1. mongodb.com/atlas → бүртгэл үүсгэ (Google-ээр нэвтрэж болно)
  2. "Build a Database" → Free / M0 сонго
  3. Cluster нэр: Cluster0 (өөрчлөхгүй байж болно)
  4. Username & Password үүсгэ — санаж авч байгаарай!
  5. Network Access → "Allow access from anywhere" → 0.0.0.0/0
  6. Connect → "Drivers" → connection string хуулж ав

Connection string иймэрхүү харагдана:

mongodb+srv://username:password@cluster.xxxxx.mongodb.net/DatabaseName

← username, password = чиний үүсгэсэн хэрэглэгч, DatabaseName = database нэр

Энэ хичээлд ашиглах бэлэн DB:
MONGO_URL=mongodb+srv://brianerdenebold_db_user:LR54yZ2vQfEOvsTD@projects.xml7qah.mongodb.net/Songs

Өөрийн Atlas үүсгэж чадахгүй бол энэ URL-г ашиглаж болно.

VS Code дотор шинэ файл үүсгэ: .env

MONGO_URL=mongodb+srv://brianerdenebold_db_user:LR54yZ2vQfEOvsTD@projects.xml7qah.mongodb.net/Songs

Шинэ файл үүсгэ: .gitignore

node_modules .env

.env нууц үгтэй тул заавал оруулахгүй байна — мэдэгдвэл хэн ч чиний database-д орж болно!
6

index.js — бүх код энэ нэг файлд

VS Code дотор index.js файл үүсгэж доорх кодыг хуулаад нааж тавь. Мөр бүрийг ойлгуулна:

А хэсэг — package-уудыг дуудах

require('dotenv').config(); ← .env файлыг унш const express = require('express'); ← express-г авчир const mongoose = require('mongoose'); ← mongoose-г авчир

require() = "энэ package-г ашиглах гэж байна" гэж зарлах.

Б хэсэг — сервер үүсгэж MongoDB холбох

const app = express(); ← "app" нэртэй сервер үүсгэнэ app.use(express.json()); ← JSON өгөгдөл хүлээн авч чадна болно mongoose.connect(process.env.MONGO_URL) .then(() => console.log('MongoDB холбогдлоо ✓')) .catch(err => console.log('Алдаа:', err));

process.env.MONGO_URL = .env файлаас MONGO_URL-г авна.

В хэсэг — Schema болон Model үүсгэх

const songSchema = new mongoose.Schema({ title: { type: String, required: true }, ← дуу нэр (заавал) artist: { type: String, required: true }, ← дуучин (заавал) genre: { type: String, default: 'Pop' } ← төрөл (заавал биш) }); const Song = mongoose.model('Song', songSchema);
Schema = загвар / хэлбэр
"Дуу гэдэг нь title, artist, genre-тэй байна" гэдгийг тодорхойлно
Model = MongoDB-тай ярих хэрэгсэл
Song.find(), Song.create() гэж ашиглана

Г хэсэг — Routes (хаяг бүр дээр яах вэ)

// GET /songs → бүх дуу авах app.get('/songs', async (req, res) => { const songs = await Song.find(); res.json(songs); }); // POST /songs → шинэ дуу нэмэх app.post('/songs', async (req, res) => { const song = await Song.create(req.body); res.json(song); }); // DELETE /songs/:id → ID-аар устгах app.delete('/songs/:id', async (req, res) => { await Song.findByIdAndDelete(req.params.id); res.json({ message: 'Устгагдлаа' }); });
req request — хэрэглэгч илгээсэн зүйл. req.body нь POST-ын мэдээлэл.
res response — сервер буцаах хариу. res.json() нь JSON болгоно.
async/await MongoDB-с өгөгдөл авахад хугацаа хэрэгтэй. await = "дуусаад ирэх хүртэл хүлээ".
:id URL дотор хувьсагч. /songs/abc123 гэвэл req.params.id = "abc123".

Д хэсэг — Сервер эхлүүлэх

const PORT = process.env.PORT || 3000; app.listen(PORT, () => { console.log(`Сервер port ${PORT} дээр ажиллаж байна`); });

|| 3000 = "PORT байхгүй бол 3000 ашиглана" (Render deploy хийхэд PORT өөрөө тавьдаг).

Бүтэн index.js — хуулж нааж тавь

Дээрх бүх хэсгийг нэгтгэсэн бүтэн файл:

require('dotenv').config(); const express = require('express'); const mongoose = require('mongoose'); const app = express(); app.use(express.json()); mongoose.connect(process.env.MONGO_URL) .then(() => console.log('MongoDB холбогдлоо ✓')) .catch(err => console.log('Алдаа:', err)); const songSchema = new mongoose.Schema({ title: { type: String, required: true }, artist: { type: String, required: true }, genre: { type: String, default: 'Pop' } }); const Song = mongoose.model('Song', songSchema); app.get('/songs', async (req, res) => { const songs = await Song.find(); res.json(songs); }); app.post('/songs', async (req, res) => { const song = await Song.create(req.body); res.json(song); }); app.delete('/songs/:id', async (req, res) => { await Song.findByIdAndDelete(req.params.id); res.json({ message: 'Устгагдлаа' }); }); const PORT = process.env.PORT || 3000; app.listen(PORT, () => console.log(`Port ${PORT}`));

Файлын бүтэц шалгах

Энэ үед чиний хавтас яг ингэж харагдах ёстой:

my-songs-api/ ├── index.js ← бүх код ├── .env ← MONGO_URL (нууц!) ├── .gitignore ← node_modules, .env ├── package.json ← автоматаар үүссэн └── node_modules/ ← автоматаар үүссэн
5 файл байх ёстой. .env эсвэл .gitignore байхгүй бол дахин үүсгэ.
8

Ажиллуулж тест хийх

Терминалд ажиллуул:

node index.js

Ингэж харагдвал зөв:

MongoDB холбогдлоо ✓ Port 3000 дээр ажиллаж байна

GET тест — Browser дотор нээ:

http://localhost:3000/songs

Хоосон array [ ] харагдана — өгөгдөл байхгүй учраас зөв.

POST тест — Thunder Client ашиглах:

POST http://localhost:3000/songs

Body → JSON сонго — эдгээр дуунуудыг нэг нэгээр нэм:

// 1-р дуу { "title": "Blinding Lights", "artist": "The Weeknd", "genre": "Pop" }
// 2-р дуу { "title": "Dynamite", "artist": "BTS", "genre": "K-pop" }
// 3-р дуу { "title": "As It Was", "artist": "Harry Styles", "genre": "Pop" }

Нэмсний дараа GET /songs дуудвал яг ингэж харагдана:

[ { "_id": "abc1...", "title": "Blinding Lights", "artist": "The Weeknd", "genre": "Pop" }, { "_id": "abc2...", "title": "Dynamite", "artist": "BTS", "genre": "K-pop" }, { "_id": "abc3...", "title": "As It Was", "artist": "Harry Styles", "genre": "Pop" } ]

DELETE тест:

DELETE http://localhost:3000/songs/<id>

GET-ийн хариуд байгаа "_id" утгыг хуулж тав.

9

GitHub → Render — интернетэд гаргах

Одоо сервер чиний компьютер дотор л ажиллаж байна. Render.com-д deploy хийвэл интернетэд бүх хүн ашиглаж болно.

Эхлээд GitHub-т хий:

git init git add . git commit -m "first commit" git branch -M main git remote add origin https://github.com/чиний-нэр/my-songs-api.git git push -u origin main
Анхааруулга: .gitignore зөв байвал .env GitHub-д орохгүй — нууц аюулгүй.

Render.com дээр:

  1. render.com нэвтэрч → "New +" → "Web Service"
  2. GitHub холбоод чиний repo сонго
  3. Доорх мэдээлэл оруул:
    Build Command: npm install Start Command: node index.js
  4. Environment Variables хэсэгт нэм:
    MONGO_URL = mongodb+srv://brianerdenebold_db_user:LR54yZ2vQfEOvsTD@projects.xml7qah.mongodb.net/Songs
  5. "Create Web Service" дарна → 2-3 минут хүлээ
Дуусаад URL авна:
https://my-songs-api.onrender.com/songs
Энэ URL-г Next.js frontend-дээ ашиглана!
