← нэг файл, бүгдийг хариуцна

Шаардлага — юу хийх ёстой вэ?

1. data/artists.ts файл үүсгэх

Дор хаяж 5 уран бүтээлч нэмэх. Nene, NMN, Rokitbay болон өөрийн дуртай 2 нэмэх. Нэр, жанр, зураг, тайлбар заавал байх.

2. app/artist/[name]/page.tsx үүсгэх

params.name-аар өгөгдлөөс уран бүтээлч олж, харуулах. Олдоогүй тохиолдолд "олдсонгүй" мэдэгдэл харуулах.

3. Нүүр хуудас — map ашиглах

artists.map()-ийг ашиглан уран бүтээлч бүрийн картыг автоматаар үүсгэх. Хатуу кодолсон HTML байхгүй байх.

4. Header + Layout

Header component хийж, layout.tsx-д оруулах. Бүх хуудсанд харагдах ёстой.

Файлын бүтэц — ийм байх ёстой

music-app/ ├── app/ │ ├── artist/ │ │ └── [name]/ │ │ └── page.tsx ← динамик хуудас │ ├── layout.tsx ← Header энд │ └── page.tsx ← нүүр, map ашиглана ├── components/ │ └── Header.tsx └── data/ └── artists.ts ← 5+ уран бүтээлч

params яаж ажилладаг вэ?

Хэрэглэгч /artist/nene руу орохад params.name дотор "nene" орж ирнэ.

// /artist/nene → params.name = "nene" // /artist/nmn → params.name = "nmn" // /artist/gee → params.name = "gee" const artist = artists.find( (a) => a.name === params.name ) // find() — массиваас тохирох нэгийг олно // олдвол → artist объект // олдоогүй бол → undefined
