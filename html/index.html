CSS Position: Relative vs Absolute

CSS-д position нь элементүүдийг хаана байрлуулахыг тодорхойлдог. Хамгийн түгээмэл нь relative болон absolute. Tailwind болон CSS-ээр хоёрыг ч ашиглаж болно.

Relative Parent + Absolute Child

Absolute Box

Эцэг div-д relative ашигласнаар доторхой child box нь зөвхөн энэ эцэг div-ийн дээд баруун буланд байрлана.

Tailwind: relative on parent, absolute top-4 right-4 on child.

.parent { position: relative; }
.child { position: absolute; top: 10px; right: 10px; }

Absolute Child without Relative Parent

Absolute Box

Parent-д relative байхгүй учир absolute child нь page-д харгалзана.

Tailwind:

parent: hasn't relative
child: absolute top-4 right-4

CSS:

.child { position: absolute; top: 10px; right: 10px; }

Тайлбар:
- Relative parent нь child-г өөрийн координатад харгалзуулдаг.
- Absolute child нь parent-д хамааралтай бол сайн, хамааралгүй бол дэлгэцэн дээр байрлана.
- Common use case: Tooltip, Badge, Floating button, Modal, Dropdown menu.

Relative vs Absolute

Вэбсайт дээр relative болон absolute нь зөвхөн coordinate бус, design layout-д хэрэгтэй. Жишээ нь: notification badge, corner label, floating button.

.parent { position: relative; }
.badge { position: absolute; top: 8px; right: 8px; }

Floating Button

Absolute button нь parent-д хамааралтай байснаар зөв байрлалтай.

.container { position: relative; }
.button { position: absolute; bottom: 16px; right: 16px; }

Tailwind дээр: parent-д relative, child-д absolute top-4 right-4 гэх мэтээр бичнэ. Энэ нь header-д notification, card-д label, footer-д floating button хийхэд ашиглагдана.
