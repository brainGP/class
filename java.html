// 01

Java танилцуулга

Юу нь чухал юм бэ? Эхлэхээсээ өмнө 30 секунд.

INTRO

Java бол яагаад SPOJ-д тохиромжтой вэ?

Java бол хатуу типтэй, өргөн дэмжигдсэн хэл. SPOJ-д хурд хангалттай, жишээ маш олон, алдаа мэдэгдэх нь тодорхой.

  • Хатуу тип: int, double, String зэргийг хольж болохгүй
  • Class бүтэц: Бүх код class дотор
  • Main: Програм заавал main() функцээс эхэлнэ
Зөвлөгөө: SPOJ-д file нэр заавал Main.java, class нэр заавал Main байх ёстой.
// 02

Програмын бүтэц

Class дотор Main, Main дотор код. Бүгд адил эхэлдэг.

BASIC

Хамгийн бага Java програм

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello SPOJ");
    }
}

3 давхар хайрцаг гэж бод:

  • class Main — гадна хайрцаг (заавал)
  • main() — дотор хайрцаг (эхлэх цэг)
  • Код — хамгийн дотор
Анхаар: println — мөр алгасна. print — алгасахгүй.
// 03

Input / Output

Scanner унш → бод → хэвлэ. Бүх бодлогын суурь.

IO

Scanner ашиглах

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int a = sc.nextInt();
        int b = sc.nextInt();
        System.out.println(a + b);
    }
}

Хэрэглэх метод:

  • nextInt() — бүхэл тоо
  • nextDouble() — бутархай
  • next() — нэг үг
  • nextLine() — бүтэн мөр
SPOJ дүрэм: Input-ын форматыг яг тэр чигээр нь унш. Илүү хоосон зай хэвлэхгүй.
// 04

Хувьсагч & үйлдэл

Тоо хадгал, нэм, хас, хуваа.

DATA

Үндсэн типүүд

int a = 5;            // бүхэл тоо
double pi = 3.14;    // бутархай
String s = "Java";   // текст
boolean ok = true;  // үнэн/худал

Арифметик үйлдлүүд

a + b      // нийлбэр
a - b      // ялгавар
a * b      // үржвэр
a / b      // ноогдвор (int / int = int!)
a % b      // үлдэгдэл (modulo)
Маш чухал: 7 / 2 = 3 (бүхэл хэсэг), харин 7 % 2 = 1 (үлдэгдэл). Энэ 2 үйлдэл бараг бүх бодлогод хэрэгтэй.
// 05

Нөхцөл (if / else)

Шалга, шийдвэрлэ.

LOGIC

Энгийн if

if (a > b) {
    System.out.println(a);
} else {
    System.out.println(b);
}

Олон сонголт (else if)

if (x > 90)      System.out.println("A");
else if (x > 80) System.out.println("B");
else if (x > 70) System.out.println("C");
else              System.out.println("F");

Харьцуулах тэмдэгтүүд: == != > < >= <=

Логик: && (ба) — || (эсвэл) — ! (биш)

// 06

Давталт (for / while)

N удаа давтах, нийлбэр олох, үржвэр олох.

LOOP

for давталт

for (int i = 0; i < n; i++) {
    System.out.println(i);
}

while давталт

while (n > 0) {
    n--;
}

Нийлбэр олох загвар

int sum = 0;
for (int i = 1; i <= n; i++) {
    sum += i;
}
Pattern: Нийлбэр → 0-оос эхэл. Үржвэр → 1-ээс эхэл. Тоолох → 0-оос эхэл.
// 07

Массив

Олон тоог цуглуулж хадгална.

DATA

Массив зарлах, дүүргэх

int[] arr = new int[n];

for (int i = 0; i < n; i++) {
    arr[i] = sc.nextInt();
}

Хамгийн их утга олох

int max = arr[0];
for (int i = 1; i < n; i++) {
    if (arr[i] > max) max = arr[i];
}
Индекс: Массив 0-оос эхэлнэ. arr.length нь массивын урт.
// 08

Функц

Кодыг таслан хувааж дахин ашиглах.

ADVANCED

Энгийн функц

static int max(int a, int b) {
    if (a > b) return a;
    return b;
}

Рекурс (GCD)

static int gcd(int a, int b) {
    if (b == 0) return a;
    return gcd(b, a % b);
}
Дүрэм: main-аас гадуур, class-ын дотор зарлана. Заавал static.

SPOJ шаблон

Бүх бодлого энэ загвар дотор багтана. Copy → paste → unsh → bod → khevle.

TEMPLATE

Main.java — universal

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        // 1. INPUT
        int n = sc.nextInt();

        // 2. LOGIC
        int result = n;

        // 3. OUTPUT
        System.out.println(result);
    }
}
Сүүлийн зөвлөгөө:
① Бодлогын input/output форматыг сайн уншиж ой.
② Эхлээд цаасан дээр томьёогоо бич.
③ Бодлогыг шийдсэний дараа жижиг жишээн дээр шалга.
④ long хэрэглэ хэрэв тоо том бол (n! гэх мэт).
