JavaScript гэж юу вэ?

JavaScript нь вэб хуудас дээр интерактив функц нэмэхэд ашиглагддаг програмчлалын хэл юм. HTML, CSS-ийг дэмжин динамик хөдөлгөөнт контент үүсгэдэг.

HTML → бүтэц
CSS → дизайн
JavaScript → хөдөлгөөн ба логик

console.log("Сайн байна уу, JavaScript!");

JavaScript хэрхэн ажилладаг вэ?

User → Event → JavaScript → DOM өөрчлөгдөнө

Жишээ: Button дарна → event үүснэ → function ажиллана → текст өөрчлөгдөнө

DOM (Document Object Model) гэж юу вэ?

DOM = HTML-ийг JavaScript ашиглан удирдах боломж

const el = document.getElementById("text");
el.innerText = "Hello";
  • document → бүх HTML
  • getElementById → element авах
  • innerText → текст өөрчлөх

Event гэж юу вэ?

Event = хэрэглэгчийн үйлдэл (click, input, submit)

const btn = document.getElementById("btn");
btn.addEventListener("click", function(){
  console.log("clicked");
});
  • addEventListener → event сонсох
  • "click" → ямар event вэ
  • function → event үед ажиллах код

Функцийн төрлүүд

Энгийн функц
Arrow функц
Anonymous функц

Function vs Arrow Function

function add(a, b){
  return a + b;
}

const sum = (a, b) => {
  return a + b;
}
  • function → энгийн, хүчтэй
  • => → богино бичиглэл
  • Arrow function → this ашиглахгүй үед тохиромжтой
  • map() дээр их ашиглагддаг

JavaScript ашиглах арга

HTML-д <script> tag ашиглаж JavaScript кодыг оруулж болно.

<script>
console.log("Сайн байна уу!");
</script>

JavaScript Calculator (Нэмэх & Хасах)

Үр дүн: ...
<input type="number" id="num1" placeholder="Эхний тоо">
<input type="number" id="num2" placeholder="Хоёр дахь тоо">
<button onclick="calculate('add')">+</button>
<button onclick="calculate('subtract')">-</button>
<div id="calcResult">Үр дүн: ...</div>

<script>
// JavaScript function
function calculate(operation){
  const n1 = parseFloat(document.getElementById("num1").value) || 0;
  const n2 = parseFloat(document.getElementById("num2").value) || 0;
  let result = 0;

  if(operation === "add") result = n1 + n2;
  if(operation === "subtract") result = n1 - n2;

  document.getElementById("calcResult").innerText = "Үр дүн: " + result;
}
</script>

document.getElementById() Usage

JavaScript-д вэб элементийг авах, утга авах болон текст өөрчлөхөд document.getElementById() ашигладаг.

Энэ нь input-с утга авахад хэрэглэгдэнэ: 

let number = document.getElementById("num1").value;

Энэ нь HTML элемент доторх текстийг өөрчлөхөд хэрэглэгдэнэ: 

document.getElementById("calcResult").innerText = "Үр дүн: " + number;

Товчоор хэлбэл:

  • document.getElementById("id") → HTML элемент авах
  • .value → input эсвэл form элементээс утга авах
  • .innerText → элементийн текстийг өөрчлөх, гаргах

Event Listener гэж юу вэ?

JavaScript-д хэрэглэгчийн үйлдлийг сонсож, тухайн event болох үед function ажиллуулахад addEventListener() ашиглагддаг. Энэ нь onclick, oninput гэх мэт inline event-ээс илүү уян хатан бөгөөд олон function нэг event-д ажиллуулах боломжтой.

Үндсэн ойлголт:

  • element.addEventListener("event", function) → тухайн event-ийг сонсож function ажиллуулна.
  • Олон listener нэг event дээр нэмэх боломжтой. Inline onclick бол нэг function л ажиллана.
  • Event function нь тухайн элементийг удирдах this объект болон event object (e) ашиглах боломжтой.
  • Хэрэгцээгүй listener-ийг removeEventListener ашиглан устгах боломжтой.
  • Тухайн event болох хүртэл function ажиллахгүй.

getElementById vs addEventListener vs removeEventListener:

  • getElementById: HTML элементийг авна. .value эсвэл .innerText ашиглан утга авах, текст өөрчлөхөд хэрэглэгдэнэ.
  • addEventListener: Event-д function ажиллуулахад хэрэглэгдэнэ (click, input, mouseover, submit, keydown гэх мэт). Олон listener нэг event-д нэмэх боломжтой.
  • removeEventListener: addEventListener-ээр нэмсэн listener-ийг устгана. Ингэснээр тухайн function дахин ажиллахгүй болно.
  • Жишээ: Input-д утга авахад getElementById ашиглана, button дарсан event-д function ажиллуулахад addEventListener хэрэглэнэ. Хэрвээ нэг товчийг зөвхөн нэг удаа ажиллуулахыг хүсвэл removeEventListener ашиглана.

Жишээ:

<button id="btnClick">Click Me</button>
<p id="output"></p>

<script>
const button = document.getElementById("btnClick");
const output = document.getElementById("output");

button.addEventListener("click", function(){
  output.innerText = "Button дарлаа!";
});
</script>

Товч тайлбар:

  • getElementById: Элемент авна
  • .value / .innerText: Элементээс утга авах эсвэл текст өөрчлөх
  • addEventListener: Event сонсож function ажиллуулна
  • Олон listener нэг event дээр нэмэж болно, .onclick бол нэг function л ажиллана

Event Listener – Төрөл бүрийн ашиглалт

Энд бид click, input, mouseover, keydown, submit зэрэг event-үүдийг хэрхэн ашиглахыг харуулсан жишээнүүдийг үзэх болно. Мөн function устгах жишээ оруулсан.

<button id="clickBtn">Click Me</button>
<p id="clickOutput"></p>

<script>
const clickBtn = document.getElementById("clickBtn");
const clickOutput = document.getElementById("clickOutput");
clickBtn.addEventListener("click", function(){
  clickOutput.innerText = "Button дарлаа!";
});
</script>
<input type="text" id="textInput" placeholder="Type something">
<p id="inputOutput"></p>

<script>
const textInput = document.getElementById("textInput");
const inputOutput = document.getElementById("inputOutput");
textInput.addEventListener("input", function(){
  inputOutput.innerText = "Текст: " + textInput.value;
});
</script>
<div id="hoverBox" style="width:200px;height:100px;background:#ccc;text-align:center;line-height:100px;">Hover over me</div>
<p id="hoverOutput"></p>

<script>
const hoverBox = document.getElementById("hoverBox");
const hoverOutput = document.getElementById("hoverOutput");
hoverBox.addEventListener("mouseover", function(){
  hoverOutput.innerText = "Mouse over!";
});
hoverBox.addEventListener("mouseout", function(){
  hoverOutput.innerText = "Mouse out!";
});
</script>
<input type="text" id="keyInput" placeholder="Press a key">
<p id="keyOutput"></p>

<script>
const keyInput = document.getElementById("keyInput");
const keyOutput = document.getElementById("keyOutput");
keyInput.addEventListener("keydown", function(e){
  keyOutput.innerText = "You pressed: " + e.key;
});
</script>
<form id="myForm">
  <input type="text" id="formInput" placeholder="Type name">
  <button type="submit">Submit</button>
</form>
<p id="formOutput"></p>

<script>
const myForm = document.getElementById("myForm");
const formOutput = document.getElementById("formOutput");
myForm.addEventListener("submit", function(e){
  e.preventDefault(); // page reload зогсоох
  formOutput.innerText = "Form submitted: " + document.getElementById("formInput").value;
});
</script>
<button id="onceBtn">Click Once</button>
<p id="onceOutput"></p>

<script>
const onceBtn = document.getElementById("onceBtn");
const onceOutput = document.getElementById("onceOutput");
function handleClick(){
  onceOutput.innerText = "Button дарлаа! (function устсан)";
  onceBtn.removeEventListener("click", handleClick);
}
onceBtn.addEventListener("click", handleClick);
</script>

Эдгээр жишээнүүд нь оюутнуудад addEventListener-ийг click, input, mouseover, keydown, submit болон function устгах зэрэг **diff situation-д хэрхэн ашиглахыг** харуулна.

map() гэж юу вэ?

map() = array доторх бүх утгыг нэг нэгээр ажиллуулах

const names = ["Bat", "Anu"];

names.map(name => {
  console.log(name);
});
  • name → array доторх нэг элемент
  • => → function бичих богино арга
  • map → давталт (loop)

Array → UI (Mapping)

const list = document.getElementById("list");
const names = ["Bat", "Anu", "Bold"];

names.map(name => {
  const li = document.createElement("li");
  li.innerText = name;
  list.appendChild(li);
});
