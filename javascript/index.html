JavaScript гэж юу вэ?

JavaScript нь вэб хуудас дээр интерактив функц нэмэхэд ашиглагддаг програмчлалын хэл юм. HTML, CSS-ийг дэмжин динамик хөдөлгөөнт контент үүсгэдэг.

HTML → бүтэц
CSS → дизайн
JavaScript → хөдөлгөөн ба логик

console.log("Сайн байна уу, JavaScript!");

Функцийн төрлүүд

Функцийн ялгаа

  • Энгийн функц: function keyword ашиглан тодорхойлогддог, hoisting дэмждэг.
  • Arrow функц: ()=> ашиглана, this-г эцэг обьектод уялдуулдаг.
  • Anonymous функц: нэргүй функц, ихэвчлэн variable-д хадгалдаг эсвэл callback-д ашигладаг.

JavaScript ашиглах арга

HTML-д <script> tag ашиглаж JavaScript кодыг оруулж болно.

<script>
console.log("Сайн байна уу!");
</script>

JavaScript Calculator (Нэмэх & Хасах)

Үр дүн: ...
<input type="number" id="num1" placeholder="Эхний тоо">
<input type="number" id="num2" placeholder="Хоёр дахь тоо">
<button onclick="calculate('add')">+</button>
<button onclick="calculate('subtract')">-</button>
<div id="calcResult">Үр дүн: ...</div>

<script>
// JavaScript function
function calculate(operation){
  const n1 = parseFloat(document.getElementById("num1").value) || 0;
  const n2 = parseFloat(document.getElementById("num2").value) || 0;
  let result = 0;

  if(operation === "add") result = n1 + n2;
  if(operation === "subtract") result = n1 - n2;

  document.getElementById("calcResult").innerText = "Үр дүн: " + result;
}
</script>

document.getElementById() Usage

JavaScript-д вэб элементийг авах, утга авах болон текст өөрчлөхөд document.getElementById() ашигладаг.

Энэ нь input-с утга авахад хэрэглэгдэнэ: 

let number = document.getElementById("num1").value;

Энэ нь HTML элемент доторх текстийг өөрчлөхөд хэрэглэгдэнэ: 

document.getElementById("calcResult").innerText = "Үр дүн: " + number;

Товчоор хэлбэл:

  • document.getElementById("id") → HTML элемент авах
  • .value → input эсвэл form элементээс утга авах
  • .innerText → элементийн текстийг өөрчлөх, гаргах
