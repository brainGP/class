nmn/page.tsx

Нэг файл — мянган уран бүтээлчийг хариуцна. Бодит дэлхийн арга.

artist/ ← хавтас
[name]/page.tsx
↳ /artist/nene
↳ /artist/anyone...

Хэсэг 2 — Динамик Route

Яагаад динамик руу шилжих вэ?

Дөнгөж 3 уран бүтээлчид 3 файл хийлээ. Хэрэв 10 болвол 10 файл. 100 болвол 100 файл — мөн бүгд ижил бүтэцтэй. Динамик route ашиглавал нэг файлаар бүгдийг хариуцна.

7

Файлын бүтэц өөрчлөгдөнө

Гурван artists/nene, artists/nmn, artists/rokitbay хавтасны оронд — нэг artist/[name] хавтас.

Устгах зүйл

app/artists/nene/page.tsx app/artists/nmn/page.tsx app/artists/rokitbay/page.tsx

Нэмэх зүйл

app/artist/[name]/page.tsx ← нэг файл бүгдийг хариуцна data/artists.ts ← өгөгдөл нэг газарт
8

Шинэ уран бүтээлч нэмэхэд зөвхөн энд нэг блок нэмнэ. Өөр файл огт засахгүй.
9

Динамик хуудас үүсгэх

Файл: app/artist/[name]/page.tsx — энэ нэг файл бүх уран бүтээлчийн хуудсыг хариуцна.

import { artists } from "@/data/artists" export default function ArtistPage({ params, }: { params: { name: string } }) { // URL-ийн [name]-г ашиглаж өгөгдлөөс олно const artist = artists.find( (a) => a.name === params.name ) // Олдоогүй бол мэдэгдэл харуулна if (!artist) { return <p className="p-10">Уран бүтээлч олдсонгүй.</p> } return ( <div className="max-w-3xl mx-auto px-6 py-10"> <img src={artist.image} className="w-48 h-48 rounded-xl object-cover mb-6" /> <h1 className="text-3xl font-bold mb-1"> {artist.title} </h1> <p className="text-indigo-500 font-medium mb-3"> {artist.genre} </p> <p className="text-gray-600"> {artist.bio} </p> </div> ) }
10

Нүүр хуудсыг шинэчлэх

Хатуу бичсэн гурван картны оронд artists өгөгдлөөс map ашиглан автоматаар үүсгэнэ. Файл: app/page.tsx

import Link from "next/link" import { artists } from "@/data/artists" export default function HomePage() { return ( <div className="max-w-3xl mx-auto px-6 py-10"> <h1 className="text-2xl font-bold mb-6"> Уран бүтээлчид </h1> <div className="grid sm:grid-cols-3 gap-4"> {artists.map((artist) => ( <Link key={artist.name} href={`/artist/${artist.name}`} className="bg-white border rounded-xl p-5 hover:shadow-sm" > <p className="font-bold">{artist.title}</p> <p className="text-sm text-gray-500">{artist.genre}</p> </Link> ))} </div> </div> ) }
artists.map() — data/artists.ts-д байгаа уран бүтээлч бүрийг картаар харуулна. Нэмэх бүрт карт автоматаар нэмэгдэнэ.

Дууслаа!

/artist/nene, /artist/nmn, /artist/rokitbay — бүгд нэг [name]/page.tsx файлаар ажиллана. data/artists.ts-д шинэ уран бүтээлч нэмэхэд URL автоматаар үүснэ.
