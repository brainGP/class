React гэж юу вэ?

React бол Facebook/Meta-аас 2013 онд гаргасан JavaScript library бөгөөд вэбийн UI (хэрэглэгчийн интерфэйс) хийхэд зориулагдсан. Өнөөдөр дэлхийн хамгийн их ашиглагддаг frontend хэрэгсэл.

Хэн ашигладаг

Instagram, TikTok,
Airbnb, Netflix

Юу хийдэг

UI component
хийдэг library

Суурь

JavaScript мэдвэл
сурч болно

Энгийнээр:

HTML/CSS/JS-ээр хуудас хийж болно — гэхдээ том, олон хуудастай, интерактив апп хийхэд маш хэцүү болдог. React тэр хэцүүг шийддэг.

Яагаад React хэрэгтэй вэ?

Жирийн JavaScript-ийн асуудлыг харцгаая. Дараах лайк товч-ийг хийнэ гэж бодъё:

Жирийн JavaScript
// Лайк тоолуур хийх let count = 0 function like() { count = count + 1 // Гараар DOM олоод шинэчлэх document .getElementById("num") .innerText = count // 10-аас дээш бол улаан болгох if (count > 10) { document .getElementById("num") .style.color = "red" } // Хуудас томрох тусам // дахин шинэчлэх код // улам их болно... }

Асуудал: data өөрчлөгдөх бүрт DOM-ийг гараар шинэчлэх хэрэгтэй. Код их болох тусам алдаа гарах магадлал нэмэгдэнэ.

React ашиглавал
function LikeButton() { // count = өөрчлөгдөх data const [count, setCount] = useState(0) return ( <div> <p style={{ color: count > 10 ? "red" : "black" }}> {count} </p> <button onClick={() => setCount(count + 1) }> Лайк </button> </div> ) }

Шийдэл: setCount дуудахад React автоматаар UI-г шинэчилнэ. DOM гараар шинэчлэх шаардлагагүй.

React-ийн гол санаа: Data (state) өөрчлөгдөхөд UI автоматаар дагаж өөрчлөгдөнө. Та зөвхөн "data ямар байх ёстой" гэдгийг бичдэг — харуулах ажлыг React хийдэг.

JSX — HTML + JavaScript хамт

React JSX хэл ашигладаг — JavaScript функц дотор HTML бичих боломж. Эхэндээ харахад хачирхалтай боловч маш хялбар.

Жирийн JavaScript + HTML

// JavaScript файл function greet(name) { return "Сайн байна уу, " + name } // HTML файл (тусдаа) <p id="msg"></p> // JS-аас HTML-г шинэчлэх document .getElementById("msg") .innerText = greet("Бат")

React JSX — хамт бичнэ

// JSX файл (.tsx) function Greeting({ name }) { return ( // HTML шиг харагдах JSX <p> Сайн байна уу, {name}! </p> ) } // Ашиглах <Greeting name="Бат" />

JSX-ийн дүрэм:

1.
class → className болно
<div className="bg-blue-500"></div> ← class биш!
2.
JavaScript илэрхийлэл {} хаалтанд орно
const name = "Бат" <h1>Сайн байна уу, {name}!</h1>
3.
Нэг root элемент буцаах ёстой
// Буруу — 2 root элемент return <h1>...</h1> <p>...</p> // Зөв — div дотор оруулах return <div><h1>...</h1><p>...</p></div>

Component — дахин ашиглагдах блок

React-д бүх зүйл component. Component бол JSX буцаадаг JavaScript функц. Нэг удаа бичиж, хаана ч хэдэн ч удаа ашиглана.

// components/Card.tsx — нэг component function Card({ title, desc }) { return ( <div className="border rounded-xl p-4"> <h3 className="font-bold">{title}</h3> <p className="text-gray-500">{desc}</p> </div> ) } // Хуудсанд 3 удаа ашиглах export default function HomePage() { return ( <div> <Card title="iPhone" desc="Утас" /> <Card title="MacBook" desc="Зөөврийн" /> <Card title="AirPods" desc="Чихэвч" /> </div> ) }
Card component нэг удаа бичлэа — 3 өөр өгөгдлөөр 3 удаа ашигласан. Дизайн засахад нэг газар засахад бүгд шинэчлэгдэнэ.

Component бичих аргууд — rfc, rfce, rafce

Нэг component-ийг бичих 3 өөр арга байдаг. Бүгд ижил үр дүн өгдөг — зөвхөн бичих хэлбэр нь өөр.

function Function Declaration ↳ VS Code: rfc
function MyCard() { return ( <div className="p-4 border rounded"> <h2>Сайн байна уу</h2> </div> ) } export default MyCard

Уламжлалт арга. function гэдэг үгийг харахад шууд "энэ component" гэдэг нь ойлгомжтой.

const => Arrow Function ↳ VS Code: rafce
const MyCard = () => { return ( <div className="p-4 border rounded"> <h2>Сайн байна уу</h2> </div> ) } export default MyCard

Орчин үеийн бичлэг. JavaScript-д const-оор функц тодорхойлж болдог — () => бол "arrow function" гэдэг хэлбэр.

export default function Шууд export хийх ↳ VS Code: rfce
export default function MyCard() { return ( <div className="p-4 border rounded"> <h2>Сайн байна уу</h2> </div> ) }

Next.js-д хамгийн их ашиглагддаг. export default-ийг функцийн өмнө нь шууд бичнэ — дор нь тусад нь бичих шаардлагагүй.

VS Code товчлол — ES7+ React Snippets extension

Товчлол Бүтэн нэр Ялгаа
rfc React Functional Component function хэлбэр, export доор нь
rfce React Functional Component Export export default function шууд
rafc React Arrow Function Component const = () => хэлбэр, export доор нь
rafce React Arrow Function Component Export const = () => + export default

export default vs export — ялгаа нь юу вэ?

export default нэг файлд нэг л байж болно
// Header.tsx export default function Header() { return <header>...</header> } // import хийхдээ нэр өөрчилж болно import Header from "./Header" import Nav from "./Header" ← ч болно
export нэг файлд олон байж болно
// utils.ts export function add(a, b) { return a + b } export function subtract(a, b) { return a - b } // {} хаалтанд оруулж import import { add, subtract } from "./utils"
Практик дүрэм: Component файлд export default ашиглана (нэг файл = нэг component). Helper функцүүдэд export ашиглана.

State — өөрчлөгддөг data

State бол component дотор хадгалагддаг, өөрчлөгдөх боломжтой data. State өөрчлөгдөхөд React тухайн component-г автоматаар дахин харуулна.

import { useState } from "react" function Counter() { // count = одоогийн утга, setCount = өөрчлөх функц const [count, setCount] = useState(0) return ( <div> <p>Тоо: {count}</p> <button onClick={() => setCount(count + 1)}> +1 нэмэх </button> <button onClick={() => setCount(0)}> Дахин эхлэх </button> </div> ) } // Товч дарах → setCount дуудагдана // → count өөрчлөгдөнө // → React автоматаар {count} шинэчилнэ

useState(0)

Эхний утгыг тохируулна

count

Одоогийн утгыг уншина

setCount(шинэ)

Утгыг өөрчилж, UI шинэчилнэ

React дангаараа хийж чадахгүй зүйлс

React зөвхөн UI хийдэг library. Том вэбсайт хийхэд дараах зүйлс дутагдана:

Routing байхгүй

/about, /contact гэх мэт хуудас хийхдээ тусдаа package суулгаж, гараар тохируулах хэрэгтэй

SEO муу

React хуудас хэрэглэгчийн browser дотор харуулдаг тул Google хайлтад муу гардаг

Сервер тал байхгүй

Database-тэй холбогдох, нэвтрэлт хийх зэрэгт тусдаа backend сервер хэрэгтэй

Яг үүнд Next.js хэрэгтэй болдог

Next.js = React + Routing + SEO + Server + Deployment — бүгдийг нэг дор

Одоо Next.js рүү шилжье

Next.js гэж юу вэ?

Next.js бол вэбсайт хийхэд хэрэгтэй бүх зүйлийг бэлэн өгдөг framework. Хуудас хооронд шилжих (routing), серверт өгөгдөл уншуулах, SEO — бүгдийг дангаараа шийддэг.

Энгийнээр хэлбэл:

React = машины хөдөлгүүр — UI хийдэг, харин routing, SEO байхгүй

Next.js = бүтэн машин — хөдөлгүүр + жолооны хүрд + GPS + суудал, бүгд дотор

Юунд хэрэглэгддэг вэ?

Онлайн дэлгүүр (e-commerce)
Блог болон мэдээний сайт
SaaS dashboard, admin хэрэгсэл
Portfolio болон хувийн сайт
Бүрэн стек апп (database + нэвтрэлт)
API болон backend үйлчилгээ

Ашиглагчид: TikTok, Twitch, Nike, GitHub, Hulu болон олон мянган компани.

React ба Next.js — ялгаа нь юу вэ?

Чадвар React дангаараа Next.js
Routing Гараар тохируулах Автомат ✓
SEO Муу (хайлтад гардаггүй) Маш сайн ✓
Серверт харуулах Байхгүй Бэлэн байгаа ✓
API route Тусдаа сервер хэрэгтэй Дотор нь байгаа ✓
Deploy хийх Гараар тохируулах Vercel дээр 1 товшилтоор ✓

Routing — файл нь хуудас болдог

Next.js-д router тохируулах шаардлагагүй. Файл үүсгэхэд л хуудас автоматаар үүсдэг.

Файлын бүтэц

app/ ├─ page.tsx ├─ about/ │ └─ page.tsx ├─ blog/ │ ├─ page.tsx │ └─ [slug]/ │ └─ page.tsx └─ api/ └─ route.ts

Үүсэх URL хаяг

yoursite.com/ yoursite.com/about yoursite.com/blog yoursite.com/blog/post-1 yoursite.com/blog/yamarch-l yoursite.com/api

Жишээ нь:

app/about/page.tsx файл үүсгэхэд yoursite.com/about хаяг автоматаар ажилладаг. Router бичих шаардлагагүй.

Код жишээ

1. Энгийн хуудас үүсгэх

app/about/page.tsx → yoursite.com/about

export default function AboutPage() { return ( <div> <h1>Бидний тухай</h1> <p>Сайтад тавтай морилно уу!</p> </div> ) } // Файл үүсгэхэд л хуудас бэлэн болдог. // Router бичих шаардлагагүй!

2. Өгөгдөл авах — React vs Next.js

React дангаараа

function Products() { const [list, setList] = useState([]) useEffect(() => { fetch('/api/products') .then(r => r.json()) .then(d => setList(d)) }, []) return <ul>...</ul> } // Хэрэглэгч эхлээд // хоосон хуудас хардаг...

Next.js серверт

async function Products() { // Серверт ажилладаг const res = await fetch( '/api/products' ) const list = await res.json() return <ul>...</ul> } // useEffect хэрэггүй! // useState хэрэггүй! // Өгөгдөл хуудастай // хамт ирдэг ✓

3. API route — backend код Next.js дотор

app/api/route.ts → yoursite.com/api

export async function GET() { const data = [ { id: 1, name: "Бүтээгдэхүүн 1" }, { id: 2, name: "Бүтээгдэхүүн 2" }, ] return Response.json(data) } // /api хаяг руу GET хүсэлт илгээхэд // энэ функц ажилладаг. // Тусдаа сервер хэрэггүй!
