Next.js — Суулгах & Төсөл

Component, Layout, файлын бүтэц — алхам алхмаар суулгаж, Header + Footer + олон хуудастай сайт хийх.

Component гэж юу вэ?

Component бол дахин ашиглагдах UI блок. Нэг удаа бичиж, хаана ч ашиглана.

Жишээ — вэбсайтыг блокуудад хуваах

<Header />
<Card />
<Card />
<Card />
<Button /> <Button />
<Footer />

Component код хэрхэн харагдах вэ:

// components/Button.tsx export default function Button({ text }) { return ( <button className="bg-blue-500 text-white px-4 py-2 rounded"> {text} </button> ) }

Бусад хуудсанд ашиглах:

import Button from "@/components/Button" export default function HomePage() { return ( <div> <Button text="Нэвтрэх" /> <Button text="Бүртгүүлэх" /> </div> ) }
Component нэг удаа бичнэ → хаана ч хэдэн ч удаа ашиглана. Засвар хийхэд нэг газар засахад бүх хуудсанд нэгэн зэрэг өөрчлөгддөг.

Layout гэж юу вэ?

Layout бол бүх хуудасд ортсон нийтлэг бүтэц. Header, Footer гэх мэт хэрэгслүүдийг layout-д бичвэл дахин давтах шаардлагагүй болно.

Layout хэрхэн ажилладаг

Header (layout.tsx дотор — бүх хуудсанд харагдана)
{children} — дотор хуудас солигдоно
Нүүр
(page.tsx)
Тухай
(about)
Холбоо
(contact)
Footer (layout.tsx дотор — бүх хуудсанд харагдана)

layout.tsx код:

// app/layout.tsx import Header from "@/components/Header" import Footer from "@/components/Footer" export default function RootLayout({ children }) { return ( <html lang="mn"> <body> <Header /> ← бүх хуудсанд <main>{children}</main> ← хуудас солигдоно <Footer /> ← бүх хуудсанд </body> </html> ) }

Next.js суулгах — алхам алхмаар

1

Node.js суулгах

Эхлээд Node.js суулгасан эсэхийг шалгана. Terminal-д доорх командыг бичнэ:

node --version

Хэрэв тоо (жнь: v20.0.0) гарвал Node.js байна. Хэрэв алдаа гарвал nodejs.org-оос суулгана.

2

Шинэ Next.js төсөл үүсгэх

Terminal нээж, төсөлөө байрлуулах хавтас руу ороод доорх командыг ажиллуулна:

npx create-next-app@latest my-website

my-website = өөрийн төслийн нэр (латин, зай байхгүй)

3

Асуултуудад хариулах

Terminal дараах асуултуудыг нэг нэгээр асуух болно. Доорх заавраар хариулна:

Would you like to use TypeScript? Yes →
TypeScript бол JavaScript-ийн дэвшилтэт хувилбар. Кодлох үед алдааг бичих явцдаа илрүүлдэг тул хөгжүүлэхэд илүү хялбар байдаг.
JavaScript: const age = "25" + 5 → алдаагүй боловч "255" болно
TypeScript: const age: number = "25" → шууд алдаа харуулна
Would you like to use ESLint? Yes →
ESLint бол кодын чанарыг шалгадаг хэрэгсэл. Хэрэглэгдэхгүй хувьсагч, мартагдсан import зэрэг алдааг автоматаар тэмдэглэж өгдөг.
Would you like to use Tailwind CSS? Yes →
Бид аль хэдийн ашиглаж байсан Tailwind CSS — Next.js дотор ч мөн адил className ашиглан хэрэглэнэ. Бэлэн суулгагдана.
Would you like your code inside a `src/` directory? No →
src/ хавтас нэмэлт давхарга үүсгэдэг. No сонгосноор app/ хавтас шууд гадна талд байх тул хялбар байна.
src/ Yes (илүү гүн)
src/app/page.tsx
src/components/
src/ No (энгийн)
app/page.tsx
components/
Would you like to use App Router? Yes →
Next.js-д routing-ийн хоёр хувилбар байдаг. App Router бол шинэ буюу одоо ашиглагддаг стандарт хувилбар. Бид app/ хавтас ашиглан хуудас хийнэ.
Pages Router (хуучин) → pages/ хавтас
App Router (шинэ) → app/ хавтас ← бид энийг сонгоно
Would you like to customize the import alias? No →
Import alias бол файл оруулах товчлол. No сонгоход анхны тохируулгаар @/ товчлол автоматаар тохируулагдана.
Урт зам: import Button from "../../../components/Button"
@/ ашиглан: import Button from "@/components/Button"
4

Төсөл рүү орох

cd my-website
5

Хөгжүүлэлтийн серверийг эхлүүлэх

npm run dev

Terminal-д localhost:3000 гэж харагдах болно.

6

Browser-т нээх

http://localhost:3000
Next.js-ийн тавтай морилно уу хуудас харагдвал амжилттай суулгагдсан!

Бидний хийх төслийн бүтэц

Header + Footer + Нүүр + Тухай + Холбоо барих хуудастай сайт хийнэ.

my-website/ ├── app/ │ ├── layout.tsx ← Header & Footer энд │ ├── page.tsx ← / (нүүр хуудас) │ ├── about/ │ │ └── page.tsx ← /about │ └── contact/ │ └── page.tsx ← /contact ├── components/ │ ├── Header.tsx ← навигаци │ └── Footer.tsx ← footer └── public/ ← зураг, файлууд

app/

Хуудас бүгд энд. Файл нэр → URL болно.

components/

Дахин ашиглагдах хэсгүүд. Header, Footer гэх мэт.

public/

Зураг болон статик файлууд.

1. Header Component хийх

Файл: components/Header.tsx

// components/Header.tsx import Link from "next/link" export default function Header() { return ( <header className="bg-white border-b border-gray-200 px-6 py-4"> <div className="max-w-3xl mx-auto flex justify-between items-center"> <Link href="/" className="text-lg font-bold text-gray-900"> Миний сайт </Link> <nav className="flex gap-6 text-sm"> <Link href="/" className="text-gray-500 hover:text-blue-600">Нүүр</Link> <Link href="/about" className="text-gray-500 hover:text-blue-600">Тухай</Link> <Link href="/contact" className="text-gray-500 hover:text-blue-600">Холбоо</Link> </nav> </div> </header> ) }
Link vs <a> — Next.js-д хуудас шилжихдээ <a>-н оронд <Link> ашиглана. Хуудасны эхнээс дахин ачааллахгүйгээр шуурхай шилждэг.

2. Footer Component хийх

Файл: components/Footer.tsx

// components/Footer.tsx export default function Footer() { return ( <footer className="border-t border-gray-200 py-8 mt-10"> <p className="text-center text-xs text-gray-400"> © 2026 Миний сайт </p> </footer> ) }

3. Layout — Header & Footer бүх хуудсанд

Файл: app/layout.tsx

// app/layout.tsx import Header from "@/components/Header" import Footer from "@/components/Footer" import "./globals.css" export default function RootLayout({ children, }: { children: React.ReactNode }) { return ( <html lang="mn"> <body className="bg-gray-50 text-gray-800"> <Header /> <main>{children}</main> <Footer /> </body> </html> ) }
{children} — хуудас солигдох газар. Нүүр хуудас үзэхэд app/page.tsx, /about руу ороход app/about/page.tsx орж ирдэг.

4. Хуудас бүр тусдаа файл

Нүүр хуудас

Файл: app/page.tsx → хаяг: /

export default function HomePage() { return ( <div className="max-w-3xl mx-auto px-6 py-16 text-center"> <h1 className="text-4xl font-bold mb-4"> Тавтай морилно уу! </h1> <p className="text-gray-500"> Энэ бол миний Next.js сайт. </p> </div> ) }

Тухай хуудас

Файл: app/about/page.tsx → хаяг: /about

export default function AboutPage() { return ( <div className="max-w-3xl mx-auto px-6 py-10"> <h1 className="text-2xl font-bold mb-4">Бидний тухай</h1> <p className="text-gray-600"> Бид веб хөгжүүлэлт заадаг. </p> </div> ) }

Холбоо барих хуудас

Файл: app/contact/page.tsx → хаяг: /contact

export default function ContactPage() { return ( <div className="max-w-3xl mx-auto px-6 py-10"> <h1 className="text-2xl font-bold mb-6">Холбоо барих</h1> <input className="w-full border rounded-lg p-2 mb-3" placeholder="Нэр" /> <textarea className="w-full border rounded-lg p-2 mb-3" placeholder="Мэдэгдэл" /> <button className="bg-blue-500 text-white px-6 py-2 rounded-lg"> Илгээх </button> </div> ) }

Товчлол — юу хийснийг санах

1

Component = дахин ашиглагдах UI блок

Header, Footer, Button — нэг удаа бичиж, олон газар ашиглана

2

Layout = бүх хуудасд нийтлэг бүтэц

app/layout.tsx — Header, Footer нэг газарт

3

Routing = файл нь хуудас болдог

app/about/page.tsx → /about автоматаар

4

Link = хуудас хооронд шилжих

<a>-н оронд <Link href="/about"> ашиглана

Дараагийн алхам:

Энэ бүтцийг ашиглаж өөрийн сайт хийгээрэй. Header, Footer хийж, дор хаяж 3 хуудас нэмж үзэх.
